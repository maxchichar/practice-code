# PROGRAMMING

## What is Programming?

Programming is speaking the computer language and giving it instructions on what you want it to do.

## Getting Started With Programming?

To master programming you need to know the 5 concept cause it doesn't matter the language your using the concept's still remains the same:

1. Variable
2. If Statement
3. Arrays
4. Loops
5. Functions

It's recommended to learn this concept's in the order above.

## Programming Language

I would say a programming language is a means to communicate to the computer to do what you want it to do.

Since the concepts are the same you can learn the concepts with one language and use it in another.
