# CONSTANTS IN PROGRAMMING

## What is a Constant?
A constant is a variable that cannot be changed after it is assigned

```js
const PI = 3.141;
console.log(PI);
```

## Constant in Practice



```js
const CARS = 7;
const STATUS = "Trilionaire"
console.log("I am a" + STATUS + " and i have" + CARS + "luxury sports")
```
